# Kodaris

Kodaris is a beginner-friendly web development project created while learning the fundamentals of HTML, CSS, and JavaScript.

This project was built for practice and experimentation during my frontend development learning journey. It helped me understand webpage structure, styling, layouts, responsiveness, and basic web development concepts.

## 🚀 About The Project

Kodaris is an educational project designed to explore and apply core frontend development concepts.

The project includes:

- HTML page structure
- CSS styling and layouts
- Basic website design principles
- Practice projects and experiments
- Media assets and resources

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Basic)
- PHP (Minor usage)

## ▶️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/vipul07bit/Kodaris.git
```

### Open the Project

1. Navigate to the project folder.
2. Open `index.html` in your browser.

Or use VS Code with the Live Server extension.
